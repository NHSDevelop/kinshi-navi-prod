# レジ機能ガイド

レジ機能は、模擬店の会計処理と売上記録を行うための機能です。

## 概要

- 商品を選択して会計処理を行うことができます。
- 会計の履歴を保存できます。

## スタッフの操作

### a.レジの操作

1. 「スタッフ画面」から「レジページ」に移動します。
2. 注文商品を選択して数量を入力し、「会計に進む」を押します。
3. 合計金額を伝え、代金を受け取ります。
4. 受取金額を入力し、会計を確定します。
5. お釣りの金額を確認し、お釣りを渡す
6. 「別の会計を開始」を押すと、新しくレジ操作を行うことができます。

### b.会計履歴の確認

- 「スタッフ画面」や「店舗管理画面」から、「レジ履歴」に移動すると、会計の履歴を確認することができます。

## 運用上の注意

- 注文商品の種類・数量を間違えて入力しないよう気を付けてください。
- 受け取った代金の入力間違えや、お釣りの受け渡しについても注意してください。
