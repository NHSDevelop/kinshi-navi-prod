# 管理者向けガイド

Kinshi Navi の管理者向け操作まとめたガイドです。
各機能のガイドについては以下のリンクを参照してください。

- [人員管理機能ガイド](management)
- [チケット機能ガイド](ticket)
- [レジ機能ガイド](register)
- [在庫管理機能ガイド](inventory)

本サービスでは、各用語を

- イベント: 金鵄祭一回（第〇回金鵄祭）
- 店舗: イベントの中のスポット（例：クラス企画、食品販売）
  - 企画: チケット機能を利用可能な店舗（1・2年クラス企画）
  - 模擬店: 在庫管理機能・レジ機能を利用可能な店舗（3年クラス販売、食品部）

としています。

## a.管理者アカウントについて

管理者アカウント（イベント管理者、店舗管理者）はそれぞれイベント・店舗の管理を行うことができます。

### 登録

※事前にGoogleアカウントの作成が必要となります。

1. 管理するイベント・店舗の既存の管理者から招待リンクを受け取り、アクセスします。
2. サインイン画面が開きますので、「Googleでサインイン」を押し、画面の操作に従ってください。
3. サインインに成功すると、自動的に組織・イベント・店舗がアカウントと紐づき、管理者画面が開きます。
4. 何も紐づいていない状態で招待リンクを受け取らずにサインインしてしまった場合は、サインイン状態で招待リンクを受け取りアクセスすることで自動的にイベント・店舗が紐づきます。
5. 既にイベント・店舗が紐づいている管理者に、新たなイベント・店舗を紐づけることはできません。

### サインイン

- 初回サインイン後は、サイト右下の「管理者ページ」から管理者画面に移動することができます。
- 管理者アカウントのユーザーページは、管理者画面右上のユーザーアイコンから確認することができます。

### 削除

- 管理者アカウントを削除したい場合は、管理者画面右上のユーザーアイコンから、「ユーザーページ」→「ユーザー設定」に移動し、「ユーザー退会」を押すと削除を行うことができます。

## c.スタッフアカウントについて

スタッフ（店舗スタッフ）は、店舗に関する操作（チケットの管理、レジなど）を行うことができます。

### 登録・サインイン・削除

b.管理者アカウントと同様の手順で行います。

### 店舗での各機能の操作

- 管理者画面から、「スタッフ画面」へ移動すると、紐づけられた店舗の種類に応じて、各種操作が行えます。
  - 店舗の種類が「企画」の場合: チケット機能に関する操作（詳しくは[チケット機能ガイド](ticket)
  - 店舗の種類が「模擬店」の場合: 在庫管理機能・レジ機能に関する操作（詳しくは[在庫管理機能ガイド](inventory)、[レジ機能ガイド](register)）

## 利用上の注意

- Googleサインインが学校等で制限されている場合は、アカウントを管理している方に"kinshi-navi.com"を許可してもらってください。
