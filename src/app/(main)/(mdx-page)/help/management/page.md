# 組織・イベント・店舗管理ガイド

管理機能は、組織・イベント・店舗を管理・公開するための機能です。
本サービスでは、各用語を

- 組織: イベントを開催する組織（例：○○高校）
- イベント: 一回の催し事（例：第〇回文化祭）
- 店舗: イベントの中のスポット（例：クラス企画、食品販売）
  - 企画: チケット機能を利用可能な店舗
  - 模擬店: 在庫管理機能・レジ機能を利用可能な店舗

としています。
店舗の種類につきましては、今後の機能拡張に合わせて追加していく予定です。

## 概要

- 組織・イベント・店舗の作成と更新を行うことができます。
- 組織・イベント・店舗の管理者、店舗の招待リンクを作成することができます。
- 組織・イベント・店舗の情報を公開することができます。

## a.組織・イベント・店舗の作成

※作成時に「識別名」を入力する箇所がありますが、識別名とは組織・イベント・店舗のURLに使われる文字列のことです。小文字英数字の8~16文字で設定してください（他の組織・イベント・店舗と重複不可）。なお、作成後に変更することはできません。

### 組織の作成

新たな組織としてサービスを利用したい場合は、利用申し込みを行う必要があります。

1. サイトトップから、画面上部の「利用の申し込み」へ移動します。
2. 「利用の申し込み」ページから、内容を確認し、「利用申し込みフォーム」を押します。
3. 開いたGoogleフォームに必要事項を入力、送信します
4. 運営事務局で確認後、1週間程度でフォームで送信していただいたメールアドレスに案内をお送りいたします。

### イベントの作成

組織管理者は、組織内にイベントを作成することができます。

1. 管理者画面から、「組織管理画面」へ移動します。
2. 「組織内のイベントの管理」の横にある「イベントを作成」を押します。
3. 「イベントを作成」ページで必要事項を入力すると、イベントが作成されます。
4. 「組織管理画面」に戻っても作成したイベントが表示されない場合、再読み込みを行ってください。

### 店舗の作成

イベント管理者（組織管理者）はイベント内（組織内のイベント内）に店舗を作成することができます。

1. 管理者画面から、「イベント管理画面」へ移動します。（組織管理者の場合は、「組織管理画面」→「組織内のイベントの管理」でイベントを選択後、「イベントページ」へ移動）
2. 「イベント内の店舗の管理」の横にある「店舗を作成」を押します。
3. 「店舗を作成」ページで必要事項を入力すると、店舗が作成されます。
4. 「イベント管理画面」に戻っても作成したイベントが表示されない場合、再読み込みを行ってください。

## b.組織・イベント・店舗情報の編集

1. 各管理画面から、「設定を編集」を押すと、情報の編集を行うことができます。
2. 「開催中か」については、作成時には「停止中」となっているので、イベント・店舗が開催するときに「開催中か」にチェックを入れてください。（今後開催日時から自動的に変更されるようになる予定です）

## c.管理者・スタッフの招待

1. 各管理画面から、イベントまたは店舗を選択し（スタッフの場合は必要なし）、「招待リンクを発行」を押します。
2. 「招待リンクを作成」ページで、招待リンクの有効回数（1~10回）を設定し、「リンクを作成」を押します。
3. 表示されたリンクをリンク横にあるコピーボタンを押してコピーし、該当する管理者やスタッフの方にメール等で送信してください。（詳しくは[管理者向けガイド]("/help/admin")）

## 運用上の注意

- 招待リンクが第三者に渡らないよう、取り扱いには十分注意してください。
